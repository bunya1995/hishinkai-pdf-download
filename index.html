Windows でのインストール

  1. ダウンロードした .exe をダブルクリック
  2. 「WindowsによってPCが保護されました」と出たら 詳細情報 → 実行
  3. PDFを右クリック → プログラムから開く → 別のプログラムを選択 → 飛信会PDF を選び「常に使う」にチェック

警告が出るのは社内アプリで発行元が未登録なためです。すでに入っている人は、上書きインストールで新しい版になります。

Mac でのインストール

  1. ダウンロードした .dmg を開き、飛信会PDF を Applications にドラッグ（すでにある場合は「置き換える」）
  2. 初回は Finder で 右クリック → 開く。「開発元を確認できません」と出たら、システム設定 → プライバシーとセキュリティ の一番下にある このまま開く
  3. PDFを右クリック → 情報を見る → このアプリケーションで開く で 飛信会PDF を選び すべてを変更…

更新について

アプリを開くと右下にバージョンが表示されます。新しい版があると「新しい版 ○○ に更新」ボタンが出るので、押してインストーラーを入れ直してください。
